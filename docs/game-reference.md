# Reference herního ovládání

Požadavek uživatele: známé ovládání a tok menu/inventáře inspirovaný Minecraftem; vlastní JOSCRAFT grafika.

Primární reference: [Minecraft Controls](https://www.minecraft.net/en-us/article/minecraft-controls), [Minecraft Education keyboard and mouse controls](https://edusupport.minecraft.net/hc/en-us/articles/360047116832-Minecraft-keyboard-and-mouse-controls), ověřeno 13. 11. 2026. Čteny pro chování kláves, inventáře a lišty; žádné bitmapy, loga, zvuky ani textury nebyly převzaty.

JOSCRAFT používá vlastní české hlavní menu, pauzu, inventář a rychlou lištu. Použitý základ: WASD, mezerník, Ctrl pro běh, Shift pro opatrný pohyb, E pro inventář, 1–9/kolečko pro lištu, levé tlačítko těží a pravé pokládá. Výchozí první osoba, F5 přepíná pohled; dřívější V je kompatibilní zkratka. Funkční rozsah této dodávky a případná omezení určuje README a testovací předání.

Textury: originální generování vestavěným image_gen. Přesné prompty v `../source/textures/prompts-v1.json`, původ a SHA v `../artifacts/texture-manifest.json`. Vlastní měkký malovaný povrch zachovává blokovou geometrii a její přesné kolize.
